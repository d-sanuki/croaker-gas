## このアプリについて

ストグラ（ストリートグラフィティ ロールプレイ）— GTAV（グランド・セフト・オートV）を元にした仮想都市「ロスサントス」を舞台とするロールプレイ — に登場する闇医者たちが、日々の業務で使っていそうだな、という想像上のアプリを観測者視点で [d_sanuki](https://x.com/d_sanuki) が、お遊びで形にしたWEBアプリです。

- 計算方法はうろ覚えのため、誤りがあればご容赦ください。
- 価格は把握していないため、スプシにいい感じに登録してください。

## 仕様

- Google スプレッドシート + Google Apps Script で作成・デプロイします。
- ブルー背景のアラート「このアプリケーションは Google Apps Script のユーザーによって作成されたものです」が表示されるのは正常です。
- GitHub からコードをダウンロードしてご自身で使用される場合は、自己責任でご自由にどうぞ。

## データ（スプレッドシート）と使い方

1. GitHub にサンプルの `xlsx` を同梱していますが、同じ構造でスプレッドシートをご用意ください。（Google ドライブにアップロードし、そのまま価格だけ書き換えて「Google スプレッドシートとして保存」すれば使用可能です。）
2. `products` シートに **name（名前）** ・ **price（価格）** で各種治療アイテムを登録します。
3. `config` シートに「治療の場合の組織入金額割合」「購入の場合の組織入金割合」「中型介入の場合の治療金額」の 3 つの定数を登録します。
4. スプレッドシートを「共有」→「リンクを知っている全員」を「閲覧者」に設定します。
5. `code.gs` の `SPREADSHEET_ID` を、使用する Google スプレッドシートの「スプレッドシート ID」に書き換えます。
6. 「デプロイ」→「新しいデプロイ」で「次のユーザーとして実行」を **自分**、「アクセスできるユーザー」を **全員** にして「デプロイ」を実行します。
7. 「ウェブアプリ」の URL をコピーしてアクセスします。
