このアプリについて

ストグラ（ストリートグラフィティ ロールプレイ）— GTAV（グランド・セフト・オートV）を元にした 仮想都市「ロスサントス」を舞台とするロールプレイ — に登場する闇医者たちが、 日々の業務で使っていそうだな、という想像を観測者視点で d_sanuki が、お遊びで形にしたWEBアプリです。

※ 計算方法はうろ覚えのため、誤りがあればご容赦ください。

※ 価格は把握していないため、暫定で全商品 10,000円 に設定しています。

仕様

Google スプレッドシート + Google Apps Script で作成・デプロイしています。

コード

https://github.com/d-sanuki/croaker-gas

GAS のコードは上記の通り GitHub に公開しています。
Analytics やその他の不審なコードは一切ございません。
不安な方はブラウザの開発者ツール（F12）の「Network」タブで通信内容をご確認ください。
ブルー背景のアラート「このアプリケーションは Google Apps Script のユーザーによって作成されたものです」が表示されるのは正常です。

GitHubからコードをダウンロードしてご自身で使用される場合は、自己責任でご自由にどうぞ。

データ（スプレッドシート）と使い方

GitHub にサンプルのxlsxを同梱していますが、同じ構造でスプレッドシートをご用意ください。 （Googleドライブにアップロード、そのまま価格だけ書き換えて「Googleスプレッドシートとして保存」すれば使用可能です。）
その後、productsシートにname（名前）,price（価格）で各種治療アイテムを登録。
configシートに「治療の場合の組織入金額割合」「購入の場合の組織入金割合」「中型介入の場合の治療金額」の3つの定数を登録。
スプレッドシートは「共有」で「リンクを知っている全員」を「閲覧者」に設定。
code.gsの「SPREADSHEET_ID」を使用するGoogleスプレッドシートの「スプレッドシートID」に書き換える。
「デプロイ」→「新しいデプロイ」で「次のユーザーとして実行」を「自分」に、「アクセスできるユーザー」を「全員」にして「デプロイ」を実行。
「ウェブアプリ」のURLをコピーしてアクセスする。
