このアプリについて

ストグラ（ストリートグラフィティ ロールプレイ）— GTAV（グランド・セフト・オートV）を元にした 仮想都市「ロスサントス」を舞台とするロールプレイ — に登場する闇医者たちが、 日々の業務で使っていそうだな、という想像上のアプリを観測者視点で d_sanuki が、お遊びで形にしたWEBアプリです。
それ以外の一般的な集計計算にも使えるようにしてみました。使うことがあるのかは分からんですが。

※ 闇医者の計算方法はうろ覚えのため、誤りがあればご容赦ください。

※ 価格は把握していないため、暫定で全商品 10,000円 に設定しています。スプレッドシートで価格設定が可能です。

リリースノート

Ver.1.1
  • 少しだけ汎用的に使えるように改修しました。
  • 区分（治療・購入）を cases シートで定義するデータ駆動方式に刷新。タブ区分の名称・組織入金率・表示順・追加をスプレッドシートだけで変更できるようになりました。
  • 設定キーを英字識別子に統一（title / intervention_amount / intervention_case / intervention_label）。表示名（日本語）と内部キーを分離しました。
  • 商品の表示区分を products シートの view 列で「区分IDのカンマ区切り」指定に変更（例：treatment,purchase）。
  • 中型介入の対象区分・固定額・表示ラベルを config で指定可能に。対象区分は任意の区分IDを指定でき、未設定時はチェックボックス自体を非表示にします。
Ver.1.0
  • 初回リリース。商品・価格の登録、個数入力によるリアルタイム計算、区分別の組織入金率・取り分の算出、リセット機能を実装。

データ（スプレッドシート）と使い方

GitHub にサンプルのxlsxを同梱していますが、同じ構造でスプレッドシートをご用意ください。 （Googleドライブにアップロードし、「Googleスプレッドシートとして保存」すれば使用可能です。）
必要なシートは cases / products / config の3つです。

casesシート（区分マスタ）：id（英字の識別子）,label（画面表示名）,rate（組織入金率。0.7＝70%）,order（表示順）を登録。
例：treatment / 治療 / 0.7 / 1、purchase / 購入 / 0.9 / 2

productsシート（商品）：name（名前）,price（価格）,view（表示する区分ID）を登録。
view は表示したい区分IDをカンマ区切りで指定（例：treatment,purchase＝両方に表示、treatment＝治療のみ）。空欄または存在しないIDのみの場合はどこにも表示されません。

configシート（設定）：key,value の2列で以下を登録。
title＝画面見出し・タブ名、intervention_amount＝中型介入時の固定請求額、intervention_case＝中型介入を表示する区分ID（例 treatment）、intervention_label＝中型介入の表示名。
中型介入を使わない場合は intervention_amount を空欄にすればチェックボックスは表示されません。

登録後の手順：スプレッドシートを「共有」で「リンクを知っている全員」を「閲覧者」に設定。
code.gsの SPREADSHEET_ID を使用するスプレッドシートのIDに書き換える。
「デプロイ」→「新しいデプロイ」で「次のユーザーとして実行」を「自分」、「アクセスできるユーザー」を「全員」にして「デプロイ」を実行。
「ウェブアプリ」のURLをコピーしてアクセスする。

※ スプレッドシートを編集しても、最大10分間はキャッシュにより反映が遅れる場合があります。即時反映したい場合は、GASエディタで clearCache を実行してからページを再読み込みしてください。
